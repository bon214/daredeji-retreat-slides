# ダレデジ合宿 2026.10.19

完成スライド93枚を表示する、GitHub Pages用の静的サイトです。

## 操作

- 左右の矢印キー、Page Up / Page Down、画面下のボタンでページを移動できます。
- ページ番号の入力、一覧からの検索・選択に対応しています。
- `F`または「全画面」で投影表示に切り替えます。
- `#slide-14`のようなURLで各スライドへ直接移動できます。
- 印刷はサイト内の「印刷」ボタンから準備してください。

## ファイル構成

- `index.html`・`viewer.css`・`viewer.js`：表示・操作用の画面
- `manifest.json`：スライドの順番とタイトル
- `assets/slides/`：スライドのHTML・CSS・図形
- `assets/fonts/`：Noto Sans JPとOFLライセンス

ビルドや外部サービスへの接続は不要です。リポジトリの`main`ブランチ・ルートをGitHub Pagesの公開元に設定します。
